# 球球星域

一款单机网页球球竞技游戏。控制自己的球吞噬光点和更小的 AI 对手，不断成长并争夺实时排行榜第一名。

## 操作

- 鼠标移动或单指拖动：控制方向
- `Space`：分裂（最多 8 个分身）
- `P` / `Esc`：暂停或继续
- `R`：重新开始

分裂后需要等待 8 秒才能重新合并。球越大移动越慢，只有明显大于对手且将其深入包裹时才会完成吞噬。

## 本地运行

需要 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

然后访问终端中显示的本地地址。

## 验证

```bash
npm test
npm run build
```

`npm test` 会检查质量守恒、吞噬条件、体积与速度、世界边界和排行榜逻辑。
